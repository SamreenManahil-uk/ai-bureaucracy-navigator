# 🧭 AI Bureaucracy Navigator & Action Agent

A full-stack **Bachelor’s Final Year Project**, selected among the **Top 3 Best Projects**, designed to simplify complex official documents into clear actions using **RAG, AI Agents, GraphQL and MERN**.

## ✨ Key Features

- 📄 Upload and process PDF documents
- 🧠 Ask grounded questions using **RAG**
- 🤖 AI Agent with **controlled Tool Calling**
- 🧾 Generate structured workflows automatically
- ✅ Human confirmation before state-changing AI actions
- 📊 Workflow progress, analytics and activity history
- 🔐 JWT Authentication, RBAC and ownership protection
- 🐳 Docker, Nginx and GitHub Actions CI/CD

## 🛠️ Tech Stack

**Frontend:** React, TypeScript, Vite, Recharts  
**Backend:** Node.js, Express, TypeScript  
**Database:** MongoDB, Mongoose  
**GraphQL:** Apollo Server  
**AI:** Qwen3, Llama 3.2, Ollama  
**RAG:** nomic-embed-text, semantic search, cosine similarity  
**Security:** JWT, RBAC  
**DevOps:** Docker, Docker Compose, Nginx, GitHub Actions  

## ⚙️ How It Works

**PDF Flow**  
Upload PDF → Extract Text → Chunk → Generate Embeddings → Store in MongoDB → Retrieve Relevant Context → LLM Response

**Workflow Flow**  
Document → AI Analysis → Structured Workflow → GraphQL → User Progress Tracking

**Agent Flow**  
User Request → AI Agent → Tool Selection → User Confirmation → Action Execution
